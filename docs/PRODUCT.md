# Localzet OS — product direction

Localzet OS is a Russian-first independent desktop product built on Ubuntu
LTS and GNOME. Russian origin and localization are product goals, not a claim
of wholly domestic source code, official registration or certification.

## Differentiation

- Aurora: one consistent desktop, settings, launcher, notifications, dock,
  accessible themes and system applications; no fake controls.
- Localzet Connect: Android phone integration via NectarLink, local-first and
  explicitly paired. No cloud account required for core OS functionality.
- Windows compatibility: Wine/Proton with isolated per-app prefixes, a tested
  compatibility catalog and honest limits; no promise of universal support.
- Developer and gaming profiles: opt-in, reproducible package transactions,
  verified sources and straightforward removal.
- Offline-first basic workflows, privacy-respecting defaults, explicit network
  permissions and visible update provenance.

## Russian-first without lock-in

- Russian and English are first-class locales; users choose language, region,
  time zone and keyboard layouts independently.
- Core installation, recovery, desktop and settings must work without an
  account or access to a proprietary external service.
- Provide Russian documentation and accessible support; do not hardcode one
  vendor, a network route, a time zone or a government service.
- Track upstream components, licenses, security updates and build provenance.
  Introduce domestic mirrors only after authenticity, reliability and fallback
  are tested; never disable signature validation.

## Evidence required before release

A bootable ISO is not an installable distribution. Require a verified BIOS/UEFI
boot, authenticated installed user, dedicated SSD safety tests, reboot from
installed disk, graphics/driver tests, recovery, updates and localization QA.
Track product claims by tested functionality and supported hardware.

Any official registry entry, procurement eligibility or certification is a
separate legal/compliance project. Do not advertise those statuses without
documented evidence.
