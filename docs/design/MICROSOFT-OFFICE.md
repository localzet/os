# Microsoft Office integration

Retain ONLYOFFICE Desktop Editors as the local offline office suite.
Microsoft 365 Web is a clearly named desktop launcher and an explicit link
in Windows Runtime. It opens the default browser on the official site;
no credentials, downloads or document uploads are performed by Localzet.

Microsoft 365 Apps for enterprise (O365ProPlusRetail, ru-ru) is an optional
Complete catalog entry for a future licensed Windows guest. The requested
offline media is not bundled, downloaded or treated as verified. Obtain
installation media through the user's entitled Microsoft account and
official instructions. Installation/activation requires applicable Windows
and Office licensing, and explicit user acceptance. Do not distribute
preactivated images, activation bypass scripts, keys or shared accounts.

Modern Microsoft 365 Click-to-Run desktop compatibility with Wine is not
established. CodeWeavers' Office 365 entry reports "Installs, Will Not Run"
on Linux. No desktop Office success claim or auto-execution of its media.

Future acceptance: dedicated Windows VM using KVM/libvirt, user-supplied
licensed Windows and Office installation, official sign-in, guest update
and reboot tests, document access and individual application launchers.
Seamless RemoteApp integration remains a separate capability; no promise
of offline full Microsoft Office before physical and guest testing.
No default document MIME association changes; ONLYOFFICE remains available.
Web launcher is included in the shared desktop package, not a native Office
binary. Network access and Microsoft account required.
