# Localzet Aurora icon artwork

The application tiles and 20 px status glyphs in this directory are first-party
Aurora artwork ported from the reviewed v1.1 design handoff. They do not use
third-party logos. The installed freedesktop theme is in
`theme/icons/Localzet`; `scripts/generate-icon-theme.py` creates its generic
actions, categories, device, MIME, place, emblem, and status glyphs.

The theme uses scalable SVG viewports and inherits `Adwaita,hicolor` for names
that Localzet does not provide. A named icon here does not imply that its
application or backend is installed.
