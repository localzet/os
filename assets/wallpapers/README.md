# Aurora wallpapers

`aurora-blue.webp`, `aurora-purple.webp` and `aurora-black.webp` are original
mountain-and-lake wallpapers prepared for the approved Aurora palette. They
are installed as selectable user backgrounds by Localzet Appearance. The
older `aurora.svg` remains available for existing build paths.

The image boards are visual references, not desktop screenshots or evidence
that the applications shown on them are implemented.
